# MongoDB Chat App 💬

A simple chat application built using Node.js, Express.js, MongoDB, and Mongoose. This project helps me understand how to create, save, retrieve, and display chat messages using a database.

## 🚀 Features

- Create a new chat message.
- Store sender, receiver, and message details.
- Save chat documents in MongoDB using Mongoose.
- Automatically record the date and time of a chat.
- Display chat messages using EJS templates.
- Handle form submissions using Express.js routes.

## 🛠️ Technologies Used

- **Node.js** — JavaScript runtime
- **Express.js** — Backend routing and server
- **MongoDB** — NoSQL database
- **Mongoose** — MongoDB object modeling
- **EJS** — Dynamic HTML templating
- **HTML & CSS** — Page structure and styling
